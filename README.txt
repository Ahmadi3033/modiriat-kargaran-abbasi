پروژه اندروید مدیریت کارگران ساختمان

این پروژه نسخه Android Studio برنامه است و وب‌اپ نسخه 2.0 را داخل یک WebView اندرویدی اجرا می‌کند.

برای ساخت APK:
1. Android Studio را نصب کنید.
2. گزینه Open را بزنید و همین پوشه را انتخاب کنید.
3. صبر کنید Gradle Sync کامل شود.
4. از منوی Build گزینه Build APK(s) را انتخاب کنید.
5. فایل APK در مسیر:
   app/build/outputs/apk/debug/app-debug.apk
   ساخته می‌شود.

ویژگی‌ها:
- کاملاً آفلاین
- بدون هاست و دامین
- چند پروژه
- کارگران و عکس
- حضور و غیاب
- تومان و افغانی
- پرداخت‌ها و گزارش
- رمز ورود
- بکاپ

نکته: این محیط امکان نصب Android SDK و Gradle و تولید APK امضاشده را نداشت؛ بنابراین پروژه کامل Android Studio آماده شده تا APK از آن Build شود.
